# BAHUMIN (Bapak Humor Indonesia): Arcade Warkop (Game Art Direction & Design System)

## 1. Konsep Visual Game UI
BAHUMIN bertransformasi dari sekadar aplikasi kuis web menjadi **Arcade Card Game & Humor Arena** bertema "Bapak-bapak Warkop Legendaris". Kesan visual memadukan estetika *retro arcade game* (pixel/retro accents, badge tebal, border emas/perunggu, stamp stempel kedai kopi) dengan sentuhan **Glassmorphism modern** (frosted cards ber-blur, neon amber glow, dan kartu tebakan interaktif ala kartu menu jadul).

## 2. Palet Warna Game (Arcade Warkop Edition)
- **Primary / Action** (#E11D48): *Hot Chili Red* — Tombol aksi utama, nyawa/HP, badge level tinggi.
- **Accent / XP & Gold** (#F59E0B): *Arcade Amber* — XP, koin, bintang, dan sorotan kemenangan.
- **Warkop Green** (#065F46): *Deep Felt Green* — Latar meja biliar/warung kopi klasik.
- **Paper Cream** (#FEF3C7): *Vintage Receipt* — Latar kartu tebakan dan dialog bapak-bapak.
- **Card Dark Surface** (#18181B): *Zinc Arcade* — Panel gelap berkesan mendalam dengan border neon tipis.
- **Success / Correct** (#10B981): *Punchline Emerald* — Tanda jawaban benar.
- **Error / Garing** (#EF4444): *Garing Crimson* — Tanda jawaban meleset / garing.

## 3. Tipografi Game
- **Heading / Game Title**: `Playfair Display` (Bold, italic, heavy drop-shadow untuk kesan koran lawas / plang warung).
- **UI & Button**: `Source Sans 3` (Clean, tegas, mudah dibaca saat cepat).
- **Score / XP / Stats**: `Fira Code` (Monospace bergaya arcade digital score).

## 4. Komponen Game UI (Arcade Style)
- **Game Card**: Kartu tebakan berbingkai tebal ala kartu pos/menu warkop dengan efek hover "lift & tilt" serta stempel sudut.
- **XP & Level Badge**: Emblem pangkat berbentuk lencana militer/kedai kopi (Anak Baru, Suhu Warkop, Dewa Garing, Kelas Badak).
- **Arcade Action Buttons**: Tombol tebal dengan efek 3D bevel dan glow saat disentuh.
- **Punchline Reveal Box**: Kotak dialog bertekstur kertas lawas yang terbuka dramatis saat jawaban benar/salah dibuka.
